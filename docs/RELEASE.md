# 1.0.0 · 首次公开源码

发布日期：2026-09-08。

包含抽象格斗、抽象回合战、抽象自走棋三个模式，60 名角色、13 张场景及 18 首程序合成配乐。提供可直接编辑的网页源码、运行素材、开发文档、规则测试与打包脚本。

网页包无需后端即可运行，可部署到 Cloudflare Pages 等静态托管服务。自走棋支持旧赛事存档迁移；浏览器存档不跨域名或设备同步。

自带测试覆盖技能资源规则、综合布阵和缓存等价性，检查脚本验证页面与图片引用。测试范围和操作方式见 [开发指南](DEVELOPMENT.md)。
